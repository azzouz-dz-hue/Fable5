Comment procéder

  1. Ajoutez votre banque ci-dessus, avec l'adresse de son site.
  2. Déposez vos identifiants : ils vont dans le coffre de Windows, jamais dans un fichier.
  3. Enregistrez le parcours : une fenêtre de navigateur s'ouvre. Faites-y votre manipulation habituelle jusqu'au téléchargement du relevé, puis cliquez sur « J'ai terminé ».
  4. Lancez l'extraction : le logiciel refait tout seul ce que vous avez montré.

Vos réglages sont dans {{ config_path }}. Les relevés et exports sont déposés dans le dossier data.
